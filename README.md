🚀Zenthra is a full-stack Employee Goal Management System developed using React.js, Node.js, Express.js, and MongoDB. The platform allows employees to create, manage, and submit goals while enabling managers to monitor, review, and approve employee performance workflows through a role-based dashboard system. It includes secure authentication, goal tracking, analytics, responsive UI, and real-time status management. The project is designed to simplify organizational performance management and improve transparency between employees and managers.


🚀This project is developed for educational and hackathon purposes.
