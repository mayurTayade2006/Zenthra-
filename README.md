# AtomQuest Goal Setting & Tracking Portal

Enterprise Goal & Performance Management System

## Overview
A production-quality enterprise web application for goal setting and performance tracking, built with the MERN stack.

## Tech Stack
- MongoDB
- Express.js
- React (Vite)
- Node.js
- Tailwind CSS

## Architecture
- `frontend/`: React + Vite application
- `backend/`: Node.js + Express API

## Quick Start
1. `cd backend && npm install && npm start`
2. `cd frontend && npm install && npm run dev`
